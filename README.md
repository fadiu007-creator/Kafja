# Kafja ☕

A simple community app for listing coffee shops, coffee prices, and whether water is served.

## MVP
- Search by café or city
- Filter by water: all / yes / no
- Sort by newest, price, or name
- Add a café from the form
- Responsive mobile-first UI
- Local browser persistence with localStorage

## Run
No dependencies or build step. Open index.html in a browser.

## Next backend step
For shared listings across all users, connect the same UI to Supabase with a `coffee_shops` table. This MVP intentionally works without credentials so it can be opened immediately.
